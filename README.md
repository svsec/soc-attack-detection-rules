# Hands-on Lab: Wazuh, Suricata IDS, and Kali Linux

Лабораторный стенд для изучения SIEM, анализа сетевого трафика и обнаружения подозрительной активности.

## Стенд

**Kali Linux** — используется для генерации сетевого трафика и проведения сканирования портов с помощью Nmap.
**Ubuntu Server** — установлен Suricata IDS для обнаружения сетевой активности. Для анализа трафика используется tcpdump.
**Wazuh** — SIEM для мониторинга событий безопасности.

## Сценарии обнаружения

| Сценарий      | Команда Nmap           | SID Suricata | Статус    |
| ------------- | ---------------------- | ------------ | --------- |
| TCP SYN scan  | `-sS`                  | `1000002`    | Выполнено |
| TCP FIN scan  | `-sF`                  | `1000003`    | Выполнено |
| TCP Xmas scan | `-sX`                  | `1000004`    | Выполнено |
| TCP NULL scan | `-sN`                  | `1000005`    | Выполнено |
| Slow SYN scan | `-sS --scan-delay 10s` | `1000006`    | Выполнено |
## Linux

Практика по правам доступа, владельцам и метаданным файлов:

- права файлов и каталогов;
- `chmod`, `chown`, `chgrp`;
- `stat`, inode и временные метки;
- проверка доступа от имени другого пользователя;
- атрибуты файла `chattr` и `lsattr`.

## Структура проекта

- `rules/suricata/` — правила Suricata.
- `scenarios/01-recon/` — сценарии обнаружения сканирования портов.
- `setup/` — материалы по настройке стенда.
- `linux/permissions/` — практика по правам доступа и метаданным Linux.

В сценариях фиксируются цель проверки, команда для воспроизведения, логика правила и результат. Скриншоты используются как подтверждение проведённой практики.
