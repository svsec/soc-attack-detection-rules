# Linux Processes — SOC Lab

## Цель

Изучить основы работы с процессами Linux и освоить базовые команды для их просмотра, анализа и управления в контексте работы SOC-аналитика.

## 1. Основные понятия

- **Процесс (Process)** — выполняющийся экземпляр программы.
- **PID (Process ID)** — идентификатор процесса.
- **PPID (Parent Process ID)** — идентификатор родительского процесса.
- **Родительский и дочерний процессы** — процессы, связанные отношением создания.
- **Состояние процесса (Process State)** — текущее состояние процесса.
- **Сигнал (Signal)** — механизм уведомления процесса или управления его завершением.

### Создание и запуск процессов

- `fork()` создаёт дочерний процесс.
- `execve()` заменяет исполняемую программу текущего процесса другой программой. Обычно PID при этом сохраняется.

## 2. Просмотр процессов

### Команда `ps`

Позволяет просматривать информацию о процессах.

```bash
ps
ps -f
ps -f -p PID
ps -o pid,ppid,user,stat,cmd -p PID
```

- `ps` — просмотр процессов, связанных с текущим терминалом.
- `ps -f` — вывод дополнительной информации, включая PID и PPID.
- `ps -f -p PID` — просмотр конкретного процесса по PID.
- `ps -o` — выбор полей, отображаемых в результате.

### Команда `pgrep`

Позволяет находить процессы по имени.

```bash
pgrep -a sleep
```

Параметр `-a` выводит PID и командную строку процесса.

### Утилита `htop`

Интерактивный инструмент мониторинга процессов. Позволяет просматривать процессы, их состояние, потребление CPU и памяти, а также отношения между родительскими и дочерними процессами.

## 3. Состояния процессов

- **R** — процесс выполняется или готов к выполнению.
- **S** — процесс находится в прерываемом ожидании.
- **D** — процесс находится в непрерываемом ожидании, часто связанном с операциями ввода-вывода.
- **T** — процесс остановлен или трассируется.
- **Z** — процесс завершён, но его родитель ещё не забрал статус завершения.

Зомби-процесс уже завершил работу. Отправка `SIGKILL` не устранит его: родитель обычно должен забрать статус завершения.

## 4. Работа с фоновыми процессами

### Запуск процесса в фоне

```bash
sleep 60 &
```

### Просмотр фоновых заданий

```bash
jobs
```

### Перевод задания на передний план

```bash
fg %1
```

Сочетание `Ctrl+C` прерывает команду, выполняющуюся на переднем плане.

## 5. Сигналы завершения процессов

### SIGTERM

```bash
kill PID
```

По умолчанию команда `kill` отправляет сигнал `SIGTERM`. Он запрашивает завершение процесса и позволяет ему корректно закончить работу.

### SIGKILL

```bash
kill -9 PID
```

Отправляет сигнал `SIGKILL`, который процесс не может перехватить или проигнорировать. Использовать его следует, когда обычное завершение не сработало и принудительная остановка допустима.

Вместо `PID` необходимо указывать реальный идентификатор процесса. Не следует завершать системные процессы без понимания последствий.
